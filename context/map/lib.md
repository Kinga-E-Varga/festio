# Lib — `src/lib/`

The small shared functions in `src/lib/`. Part of `context/repo-map.md`.

| File                 | Holds                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config.ts`          | `GUEST_DATA_RETENTION_DAYS` — the single GDPR retention parameter. Never inline it. Also the reply-cap margins, the replies-closing-soon window, the rate limits (`REPLY_LIMIT_PER_HOUR`, `PASSWORD_LIMIT_PER_HOUR`), `UNLOCK_DAYS`, `MEMO_TTL_MINUTES`, `MEMO_MAX_ENTRIES`, `SLUG_BLOCK_DAYS`, `TERMS_VERSION` and `SESSION_DAYS`.                                                                                                                                          |
| `event.ts`           | `eventPath` (an event's dashboard pages), `invitationLink` (`<slug>.<base domain>`, as printed) / `invitationUrl` (to open or copy), `defaultReplyClose` (24h rule), `dateLocked` (from the event day), `deletionDate`, date formatting, expected-guests and reply-cap helpers, `replyClose` / `replyWindow`, `todayIn` / `spanFrom`, `shortTitle`, `isArchived` (its data is deleted)                                                                                       |
| `slug.ts`            | `RESERVED_SLUGS` (the one list), slug limits and `SLUG_PATTERN`, `normalizeSlug`, suggestions. A slug is a subdomain name; `RESERVED_SLUGS` are the subdomains Festio keeps.                                                                                                                                                                                                                                                                                                 |
| `invitation.ts`      | Template vars, `inviteTheme` (an invitation root's palette, fonts and ground), `invitationValues` (saved text over the template's fallbacks, the event's date), fallback values, `DATE_FORMATS`                                                                                                                                                                                                                                                                              |
| `fonts.ts`           | Invitation fonts via `next/font/google` (per-template, not the app chrome — that's `src/app/fonts.ts`). Also the font pairs' faces (Gelasio, Arimo, Fraunces, Space Grotesk).                                                                                                                                                                                                                                                                                                |
| `domain.ts`          | `BASE_DOMAIN` (`NEXT_PUBLIC_BASE_DOMAIN`, default `festio.eu`; `localhost:3000` in dev), `siteFor(host)` — the host app, `www` or an invitation's slug; `siteOrigin(subdomain?)` — https except on localhost; `NO_ROUTE`, the address that gets the 404 page. No path aliases: `next.config.ts` reads it                                                                                                                                                                     |
| `history.ts`         | Local visit tracking; `useLeaveFestio(fallback)` — the one BACK, with each page's own fallback when no Festio page is behind it                                                                                                                                                                                                                                                                                                                                              |
| `guests.ts`          | Guest rows from list + replies: `toGuestReplies` (reply cards → rows, shared with the seed), matching, Unknown/Duplicate tags, grouping and splitting by category, counts, filters, repeat check; `eventCounts` (the event's `counts` from its replies), `fromGuestReplies` and `guestChanges` (the editors' changes as the save sends them). No React or Firebase.                                                                                                          |
| `leave-warning.ts`   | `useLeaveWarning(active, message)` — while there are unsaved changes, asks before reload/close (the browser's prompt) and before in-app links or a `data-leaves` control (BACK)                                                                                                                                                                                                                                                                                              |
| `language.ts`        | `LANGUAGES` (the one list, read by both `i18n/routing.ts` and an invitation's `language`), `LocalizedText`/`localized`, locale tags and names, `plainText` (case- and accent-blind search)                                                                                                                                                                                                                                                                                   |
| `picked-event.ts`    | The event the nav is on: `PICKED_EVENT_COOKIE` (read in the dashboard layout), `toPickerEvent`, `resolvePicked`, `writePickedEvent` — the one place it is written                                                                                                                                                                                                                                                                                                            |
| `packages.ts`        | `PACKAGES` (prices, what each unlocks), `nextPackage`. A saved event is always paid for: no unpaid or draft state (drafts live on the device)                                                                                                                                                                                                                                                                                                                                |
| `firebase-client.ts` | `clientAuth()` — the browser's Firebase Auth, in memory, on the emulator in dev. Sign-in only; never import `@/db/admin` in the browser                                                                                                                                                                                                                                                                                                                                      |
| `action.ts`          | `orFailed(request)` — a Server Action's result, or `failed` when the request itself got no answer (offline)                                                                                                                                                                                                                                                                                                                                                                  |
| `id.ts`              | `newId()` — a random UUID; falls back to `getRandomValues` where `crypto.randomUUID` is missing (pages not on HTTPS or localhost, e.g. a phone on the dev server)                                                                                                                                                                                                                                                                                                            |
| `memo.ts`            | `createMemo({ ttlMs?, maxEntries?, now? })` — a small in-memory cache (`get` / `set` / `delete`), one per use, for the server process. Entries expire after `ttlMs`; past `maxEntries` the least recently used goes first. Values are shared: never change them. Defaults: `MEMO_TTL_MINUTES`, `MEMO_MAX_ENTRIES`                                                                                                                                                            |
| `saved-lists.ts`     | The guest list's last save per event, for the browser tab (`keptList`, `keepList`, `dropList`), so Back never starts from a page older than the save; `forgetSavedLists` on Log out                                                                                                                                                                                                                                                                                          |
| `suggested.ts`       | The seven suggested questions (age, diet, transport, song, accessibility, accommodation, phone): `SUGGESTED` (kind, scope, options, locked in code), `DEFAULT_QUESTIONS` (age and diet, on every new event), `isSuggested`, `resolveQuestions` (a stored card → the full question), `ageOf`, `dietOf`, `accessOf` and `needsOf` (a person's age, diet and accessibility needs from `answers`); diet and accessibility are the `needs` kind (options, None, Other with words) |
| `questions.ts`       | `mergeQuestions(stored, sent)` — the host's reply questions as sent, merged with the stored ones for the invitation's save: one a reply answered meanwhile is kept (archived, its type, scope and options as stored, Required only off); returns the list and the kept ids; `withAnswered(current, saved)` — the current questions (`StoredQuestion[]`) with `answered` set from the saved ones; `inputOf` — a question as the form's field                                  |
| `answers.ts`         | `checkAnswers(questions, scope, sent, rules)` — a reply's or a person's answers checked against the event's questions (`GUEST_RULES`: Required holds, archived dropped; `HOST_RULES`: neither); `markAnswered` — the questions with `answered` set, or null when none is new                                                                                                                                                                                                 |
