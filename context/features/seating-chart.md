# Seating chart (paid)

Status: **not built.** Moved out of `context/project-overview.md` to keep the always-loaded
spec small — this is the full text, nothing was dropped.

Available on tier 2 and tier 3 only (see the tiers table in the core spec).

## Spec

Host sets table count and seats per table, plus per-guest grouping criteria (can group / do
not group / must stay together). Platform auto-generates an arrangement; host can then adjust
manually and export the final chart.

## Open questions

None recorded yet. The grouping criteria above are decided; the generation algorithm, the
manual-adjust UI and the export format are all unspecified.
